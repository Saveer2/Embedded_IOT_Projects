## Smart Embedded & IoT Projects

* A collection of embedded systems and IoT projects focused on practical hardware–software integration and real-world applications.
* The repository includes projects built using Arduino, ESP32, STM32, GSM modules, and sensors, following structured and industry-oriented development practices.

---

*Technologies Used*

Microcontrollers: Arduino, ESP32, STM32

Programming: Embedded C / C++

Communication: Wi-Fi, GSM, UART, I2C, SPI

Development Tools: Arduino IDE, STM32CubeIDE
